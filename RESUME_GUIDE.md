# Resume Project Guide

## How to Present This Project on Your Resume

### Project Title
**Task Management System - Command Line Application**

### One-Line Description
A feature-rich CLI task management application in C++14 demonstrating OOP principles, data persistence, and modern C++ practices.

### Resume Bullet Points (Choose 2-3)

✅ **Developed a task management system in C++14** with object-oriented design, featuring CRUD operations, priority-based task organization, and file-based data persistence

✅ **Implemented smart pointer-based memory management** using std::unique_ptr to ensure efficient resource handling and prevent memory leaks

✅ **Designed a user-friendly command-line interface** with 9 core features including task creation, status tracking, search functionality, and statistical analytics

✅ **Built a modular architecture** with separate Task and TaskManager classes, demonstrating separation of concerns and maintainable code structure

✅ **Utilized C++ STL extensively** including vectors, file streams, and lambda functions for efficient data management and processing

### Interview Talking Points

**Q: Tell me about this project**
- Explain the purpose: organize and track tasks with priorities and due dates
- Mention the technical challenge: implementing persistent storage without database
- Highlight the design: clean OOP structure with Task and TaskManager classes

**Q: What did you learn?**
- Modern C++ features like smart pointers for automatic memory management
- File I/O for data persistence
- Designing intuitive user interfaces
- Software architecture and modular design

**Q: What would you improve?**
- Add unit tests using Google Test framework
- Implement database backend (SQLite)
- Add recurring tasks feature
- Export tasks to different formats (JSON, CSV)
- Add task categories/tags
