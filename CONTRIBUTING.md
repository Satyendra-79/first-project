# Contributing to Task Management System

Thank you for considering contributing to this project! 🎉

## How to Contribute

### Reporting Bugs

- Use the GitHub issue tracker
- Describe the bug in detail
- Include steps to reproduce
- Mention your environment (OS, compiler version)

### Suggesting Features

- Open an issue with the "feature request" label
- Explain the feature and its benefits
- Provide examples if possible

### Code Contributions

#### Setup Development Environment

```bash
git clone https://github.com/Satyendra-79/first-project.git
cd first-project
make test
```

#### Code Style

- Follow C++14 standard
- Use consistent indentation (4 spaces)
- Write clear, self-documenting code
- Add comments for complex logic
- Run `make format` before committing

#### Testing

- Add tests for new features
- Ensure all tests pass: `make test`
- Verify build with: `make clean all`

#### Pull Request Process

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/amazing-feature`
3. Commit your changes: `git commit -m 'Add amazing feature'`
4. Push to the branch: `git push origin feature/amazing-feature`
5. Open a Pull Request

### Code Review

- All submissions require review
- Address feedback promptly
- Keep discussions professional and constructive

## Development Guidelines

### Commit Messages

- Use present tense ("Add feature" not "Added feature")
- Be descriptive but concise
- Reference issues when applicable

### Documentation

- Update README.md for new features
- Add inline documentation for public APIs
- Update help text if adding commands

## Questions?

Feel free to open an issue for questions or discussion!

Thank you for contributing! 🚀
